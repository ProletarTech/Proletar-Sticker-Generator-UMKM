3Unduh hasilnya

PDF = file siap cetak (paling tajam). PNG = gambar lembar stiker. SVG = garis potong untuk mesin potong.

Panduan potong (kiss cut / die cut)
  • PDF: gambar cetak + garis potong vektor magenta (tebal 0,1 mm) di atasnya. Matikan centang kalau mau PDF cetak saja.
  • SVG: hanya garis potong (grup CutContour) dan tanda registrasi, vektor murni. Bisa di-import ke CorelDRAW, Illustrator, atau software mesin.
  • Kiss cut = pisau hanya memotong lapisan stiker, backing tidak tembus. Die cut = potong tembus. Ini diatur di mesin (force, kedalaman pisau), bukan di file.
  • Mesin Roland/Summa biasanya membaca garis potong dari warna spot bernama CutContour. Di CorelDRAW, beri nama spot color itu pada garis magenta setelah import.
  • Tanda registrasi tiap merek mesin beda (Graphtec ARMS, Summa OPOS, dll). Titik dan siku di file ini bentuk umum, jadi kalau mesinmu butuh format khusus, tambahkan tanda dari software mesinnya.
  • Selalu tes potong satu lembar dulu untuk atur force dan offset.

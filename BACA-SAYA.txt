PROLETAR PROJECT STICKER GENERATOR (aplikasi web / PWA)

Isi folder ini harus diunggah SEMUA ke hosting HTTPS, lalu dibuka dari alamatnya:
- index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, icon-maskable-512.png

Cara pasang jadi aplikasi (tanpa Play Store):
1. Unggah folder ke hosting gratis: Netlify Drop (app.netlify.com/drop), GitHub Pages, atau Cloudflare Pages.
2. Buka alamatnya di Chrome HP, lalu menu titik tiga > "Pasang aplikasi" / "Tambahkan ke layar utama".
   Di layar intro juga akan muncul tombol "Pasang sebagai aplikasi".
3. Setelah terpasang, aplikasi bisa dibuka offline (semua file sudah tersimpan).

Mau jadi file APK untuk dibagikan atau Play Store?
- Buka pwabuilder.com, masukkan alamat hosting tadi, pilih Android, unduh paketnya.
- Atau bungkus dengan Capacitor / Bubblewrap bila ingin dikembangkan lebih lanjut.

Catatan: file index.html di dalam folder ini tidak bisa diinstal bila hanya dibuka langsung dari penyimpanan HP (file://). Harus lewat hosting HTTPS.

Batas gambar dan ekspor:
- Gambar maksimal 25 MB dan 25 megapiksel. Gambar di atas 12 megapiksel akan meminta konfirmasi karena dapat memakai banyak memori.
- PNG dibatasi maksimal 25 megapiksel dan sisi terpanjang 12.000 piksel. Jika batas perangkat tercapai saat membuat PNG atau PDF, pilih coba lagi, turunkan resolusi otomatis, atau batalkan.
- Saat resolusi diturunkan, aplikasi mencoba bertahap dan menampilkan ukuran serta DPI hasil akhirnya. PDF lossless dapat beralih ke raster beresolusi lebih rendah hanya jika pengguna memilih menurunkan resolusi.

Penghapus latar:
- "Hapus latar otomatis" mendeteksi warna dari sudut gambar; warna serupa di bagian lain gambar juga dapat ikut terhapus.
- "Magic Eraser" menghapus area dengan warna serupa yang tersambung dengan titik yang diklik. Klik titik lain untuk menambah area yang dihapus.
- Undo/redo tersedia untuk kedua alat (Ctrl+Z dan Ctrl+Y; di Mac Cmd+Z dan Cmd+Shift+Z). Riwayat menyimpan maksimal 8 langkah atau 128 MB agar penggunaan memori tetap terbatas.
- Kedua alat berjalan sepenuhnya di perangkat. Hasilnya dapat diunduh atau dikirim ke Studio Warna dan Lembar Stiker.

Upscaler:
- Tab Upscaler memperbesar gambar 2×, 3×, atau 4× sepenuhnya offline menggunakan interpolasi browser berkualitas tinggi atau seimbang.
- Interpolasi memperhalus hasil pembesaran, tetapi tidak menciptakan detail baru seperti upscaler AI. Ukuran hasil dibatasi maksimal 25 megapiksel dan sisi 12.000 piksel; bila perangkat gagal memproses, tersedia opsi coba lagi, turunkan resolusi, atau batalkan.
- Hasil dapat diunduh sebagai PNG.
